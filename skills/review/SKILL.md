# /review - Code Review

Quality assessment and constructive feedback on changes.

## Quick Reference

- **Design**: Consistency with DESIGN.md
- **Quality**: Code readability and structure
- **Types**: TypeScript type safety
- **A11y**: Accessibility and WCAG AA
- **Performance**: Impact on speed
- **UX**: User experience and usability

## When to Use

- Before merging PRs
- Large feature reviews
- Team feedback requests
- Design system changes
- Accessibility audits

## Common Tasks

```
/review hero section changes
/review new calculator component
/review responsive design on mobile
/review accessibility improvements
```

## Review Checklist

- [ ] Design consistency
- [ ] Code quality
- [ ] TypeScript types
- [ ] Accessibility
- [ ] Responsive design
- [ ] Performance
- [ ] Thai language support
- [ ] Component reusability
