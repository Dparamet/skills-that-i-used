# /simple - Simple Tasks

Small, low-risk changes that are safe and quick to implement.

## Quick Reference

- **Copy**: Text and content updates
- **Styling**: Small color or spacing tweaks
- **Icons**: Icon or image changes
- **Props**: Simple property additions
- **Typos**: Fix grammar and spelling

## When to Use

- Quick fixes that don't need review
- Simple content updates
- Spacing or padding adjustments
- Color tweaks
- Icon replacements

## Common Tasks

```
/simple update hero headline text
/simple fix typo in FAQ
/simple increase padding on services
/simple change contact button color
/simple update copyright year
```

## Constraints

- Single file preferred
- No refactoring
- No breaking changes
- No dependency updates
- Quick visual verification only
