# /plan - Planning & Strategy

Break down larger features into actionable tasks and define implementation strategy.

## Quick Reference

- **Define**: What are we building and why?
- **Scope**: Which components are affected?
- **Requirements**: Functional and design needs
- **Tasks**: Break into step-by-step work items
- **Order**: Identify dependencies and sequence

## When to Use

- Planning new features
- Complex component updates
- Cross-section changes
- Before starting development
- To get early feedback

## Common Tasks

```
/plan solar calculator redesign
/plan portfolio carousel upgrade
/plan new FAQ section
/plan mobile navigation redesign
```

## Output

- Clear task breakdown
- Success criteria
- Implementation order
- Estimated scope
