# /fix - Bug Fixes

Quick, targeted fixes for identified issues without refactoring or scope creep.

## Quick Reference

- **Isolate**: Find the exact problem
- **Minimal**: Fix only what's broken
- **Test**: Verify the fix works
- **Document**: Explain the issue and fix

## When to Use

- Component rendering issues
- Style/layout bugs
- Navigation problems
- Form validation errors
- Language switching bugs
- State management issues

## Common Tasks

```
/fix navbar not closing on mobile
/fix calculator showing wrong value
/fix thai text alignment
/fix portfolio carousel skipping
```

## Avoid

- Refactoring while fixing
- Scope creep
- Architectural changes
