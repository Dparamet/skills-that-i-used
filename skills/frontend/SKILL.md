# /frontend - Frontend Development

Handle all frontend-related tasks: UI components, styling, layout, responsive design, and user interactions.

## Quick Reference

- **UI Components**: Create or update React components
- **Styling**: CSS, Tailwind, design tokens
- **Responsive**: Mobile-first development
- **Accessibility**: WCAG AA compliance
- **Thai Support**: Language-aware design

## When to Use

- Building new sections or components
- Styling and color system updates
- Responsive design fixes
- Icon or image work
- Animation and micro-interactions

## Common Tasks

```
/frontend fix navbar layout on mobile
/frontend create new service card component
/frontend update hero section colors
/frontend improve accessibility on calculator
```
