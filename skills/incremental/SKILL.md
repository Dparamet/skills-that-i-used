# /incremental - Step-by-Step Development

Build features incrementally with regular commits, feedback, and refinement.

## Quick Reference

- **Small steps**: Divide into mini-milestones
- **Commit often**: Each step gets its own commit
- **Feedback early**: Review after each step
- **Test incrementally**: Verify as you go
- **Iterate**: Refine based on feedback

## When to Use

- Large features
- Complex components
- Uncertain requirements
- Features needing design feedback
- Mentoring or collaboration

## Workflow

1. Define steps
2. Implement step 1
3. Get feedback
4. Implement step 2
5. Continue until complete

## Common Tasks

```
/incremental build new dashboard
/incremental redesign calculator step-by-step
/incremental create portfolio section
/incremental upgrade navigation system
```

## Benefits

- Early feedback prevents wasted effort
- Easier to spot issues
- Cleaner git history
- Better code review
- Safer merging
- Better collaboration

## Example: Solar Calculator

- Step 1: Data input form
- Step 2: Calculation logic
- Step 3: Results display
- Step 4: Assumptions disclaimer
- Step 5: Mobile styling
- Step 6: Accessibility audit
